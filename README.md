# Codex Notch 下载

这是 Codex Notch 的公开安装包仓库。应用源码保存在独立的私有仓库；这里仅提供安装包和安装说明。

## 下载

- [下载最新版安装包](https://github.com/BearEric/codex-notch-downloads/releases/latest)
- 当前版本：1.0.1（构建号 104），适用于 Apple 芯片、内建刘海屏的 macOS 14 或更新版本；需已安装并登录 Codex 桌面应用。

下载 Release 中的 `Codex-Notch-1.0.1-macOS-arm64.zip`，解压后将 `Codex Notch.app` 拖入“应用程序”文件夹。应用没有 Dock 或菜单栏图标；鼠标移入刘海区域可展开面板，并通过“···”菜单退出。

此安装包使用临时签名，尚未经过 Apple Developer ID 签名或公证。首次启动若被 macOS 阻止，请在“系统设置 → 隐私与安全性”中按系统提示选择“仍要打开”。
